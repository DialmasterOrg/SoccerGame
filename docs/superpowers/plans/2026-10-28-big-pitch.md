# The Big Pitch (7c, plan 1 of 5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** From the School Field on, a match draws on a 534×300 canvas over a 1280×128 pitch with 56×48 goals and lasts 120 s, every match's clock counts down, and the Backyard and Park play exactly as before.

**Architecture:** A `View` (canvas size, near-touchline row, HUD scale) rides on the `Camera`, and `project` reads it, so every drawing path works in either view. A `Stage` per venue bundles the field, the view and the match lengths; `createWorld` takes the stage and the match scene picks it from the venue. Scenes declare their canvas size and the screen resizes its game canvas to fit whichever is showing. At the big view the HUD draws at 1× into a 267×150 layer that is doubled onto the match canvas.

**Tech Stack:** TypeScript 7, Vite 8, Vitest 4, Canvas 2D. Node 20.

**Spec:** `docs/superpowers/specs/2026-10-28-school-field-design.md` (sections *The match canvas*, *The pitch*, *Match length and the clock*, *The HUD and effects at 534×300*; plan 1 in *Plans and release*).

## Global Constraints

- The Backyard and the Park keep the 320×180 view, the 640×64 pitch, 90-second matches and 45-second golden goal; every existing tuning, snapshot, AI-vs-AI and no-kit parity test passes unchanged (only tests naming removed constants or the reworded bonus may be edited).
- Scaling stays whole-number (`computeViewport`); no smoothing on any canvas.
- On-screen text uses only uppercase letters, digits and `' - : ! ? . , / + < >`. No parentheses.
- No image, audio or font files; everything is code.
- Work on branch `plan-7c-school-field`. Ask before any merge into `main` and any push. Run `git status --short` before every commit. Commits follow Conventional Commits 50/72 with no AI attribution trailers.
- Run tests from the project root: `npx vitest run <file>`; the whole suite with `npx vitest run`; types with `npx tsc --noEmit`; the build with `npm run build`.
- School Field matches have no catalog entries until plan 3; tests and the playtest reach the big pitch through a `CareerMatch` fixture with `venue: 'school'`.
